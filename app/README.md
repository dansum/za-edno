# Съвместна мисловна карта — приложение (Алфа 0.1)

Виж пълния план в [`../PLAN.md`](../PLAN.md).

## Стартиране в режим на разработка (локален режим, без мрежа)

```bash
npm install
npm run dev
```

Отваря се на `http://localhost:5173` (или посочен порт). Без конфигуриран
Liveblocks ключ приложението работи в **LocalOnlyProvider** — една раздяла,
данните се пазят само в `IndexedDB` на браузъра (вж. `src/sync/persistence.ts`).
Това е достатъчно за цялата Фаза 1 (редактор, клавиатура, влачене, история).

## Включване на съвместната работа (Liveblocks)

1. Регистрация на https://liveblocks.io, създаване на проект.
2. Копирай публичния ключ (Settings → API keys → Public key, започва с `pk_`).
3. Създай `.env.local` по образец на `.env.example`:
   ```
   VITE_LIVEBLOCKS_PUBLIC_KEY=pk_...
   ```
   **Файлът трябва да е UTF-8 без BOM.** `echo "..." > .env.local` в PowerShell
   записва UTF-16 и Vite пренебрегва файла мълчаливо — приложението просто
   продължава в локален режим, без съобщение за грешка. Проверка:
   `head -c 5 .env.local | xxd` трябва да покаже `VITE_`, а не `fffe`.
4. `npm run dev` отново — приложението вече ще се свързва към Liveblocks
   стая, определена от `?room=...` в адреса.

## Тестове

```bash
npm run test
```

Покрива основно защитата от цикли при местене на възли (PLAN.md §3.2),
включително симулация на двама участници, които едновременно местят
възли един под друг.
